# AmneziaWG

[← Все инструкции Liberty](README.ru.md) · [English](amneziawg.md) · **Русский**

WireGuard с маскировкой. Рукопожатие и заголовки пакетов дополняются и меняют форму
так, что оборудование DPI не опознаёт протокол, — полезно там, где обычный WireGuard
вычисляют и режут. Во всём остальном ведёт себя точно так же.

Модуль ядра в этой прошивке **совпадает по vermagic с работающим ядром**. Модуль,
скачанный откуда-то ещё, загрузиться откажется.

## Где он находится

**Liberty → AmneziaWG** — это **только страница состояния**:

![Страница состояния AmneziaWG без настроенных интерфейсов](../img/liberty/amneziawg-status.png)

Здесь ничего не настраивается. Само подключение — сетевой интерфейс, и создаётся оно
в **Network → Interfaces**. После этого здесь будут видны узлы, рукопожатия и
счётчики трафика.

## Шаг 1 — создать интерфейс

**Network → Interfaces** показывает то, что у донгла уже есть: `lan` (мост, через
который вы им и управляете) и `modem` (канал 4G). Их трогать не нужно — туннель
будет третьим, отдельным интерфейсом.

![Страница Interfaces с интерфейсами lan и modem](../img/liberty/interfaces.png)

*① **Add new interface…** внизу списка.*

![Диалог добавления интерфейса с выбранным AmneziaWG VPN](../img/liberty/interfaces-add.png)

*① **Name** — `awg0`. ② **Protocol** — **AmneziaWG VPN**. ③ **Create interface**.*

| Поле | Значение |
|---|---|
| Name | `awg0` |
| Protocol | **AmneziaWG VPN** |

**Create interface** сразу открывает диалог самого интерфейса, и шаги 2–4 целиком
происходят в нём. Если вы его закрыли, вернуться можно так: **Network → Interfaces**
→ строка `awg0` → **Edit**.

## Шаг 2 — вписать ключи

В этом диалоге, вкладка **General Settings**:

- **Private Key** — ваш, из конфигурации провайдера
- **Listen Port** — для клиента оставьте пустым
- **IP Addresses** — выданный вам адрес с маской, например `10.8.0.2/24`

## Шаг 3 — добавить узел

Вкладка **Peers** → кнопка **Add peer**. Откроется ещё один диалог:

| Поле | Значение | Примечание |
|---|---|---|
| Public Key | публичный ключ сервера | |
| Preshared Key | если провайдер выдал | необязательно |
| **Allowed IPs** | `0.0.0.0/0` | **именно это отправляет в туннель весь трафик** |
| Route Allowed IPs | **включить** | создаёт маршруты по строке выше |
| Endpoint Host / Port | адрес и порт сервера | |
| Persistent Keep Alive | `25` | держит туннель живым за NAT |

Ключевая настройка — `Allowed IPs = 0.0.0.0/0`. Всё, что уже, отправит в туннель
только перечисленные подсети, а остальное оставит на модеме. При использовании IPv6
добавьте ещё `::/0`.

## Шаг 4 — параметры маскировки

Вкладка **AmneziaWG Settings** — именно она, а не *Advanced Settings*: последняя
есть у любого интерфейса и к AmneziaWG отношения не имеет. Здесь лежат поля
**Jc**, **Jmin**, **Jmax**, **S1**–**S4**, **H1**–**H4** и **I1**–**I5**.

**Они должны в точности совпадать с сервером.** Это не настройки «под себя», а
описание формы пакетов, о которой договорились обе стороны. Одно неверное значение —
и рукопожатие не состоится, причём без внятной ошибки: интерфейс просто будет
молчать. Переносите их из конфигурации провайдера дословно.

Затем **Save**, чтобы закрыть диалог, и **Save & Apply** внизу страницы Interfaces.

## Шаг 5 — пустить всё через туннель без утечек

Дальше по инструкции [Чтобы не текло: kill-switch и DNS](kill-switch.ru.md):
создайте зону `vpn` с интерфейсом `awg0` и переведите перенаправление `lan` с `wan`
на неё. Начинайте сразу с шага 2 — `awg0` уже интерфейс, шаг 1 не нужен.

`Allowed IPs = 0.0.0.0/0` сам по себе **не** kill-switch. Он задаёт маршрут, пока
туннель поднят; когда тот упадёт, маршрут исчезнет и трафик вернётся на модем.
Защищает именно правка firewall.

## Проверка

**Liberty → AmneziaWG** показывает узел и время последнего рукопожатия — **Latest
handshake**. Рукопожатие в пределах пары минут означает, что туннель действительно
живой; одни лишь счётчики трафика могут выглядеть правдоподобно, когда ничего не
работает.
