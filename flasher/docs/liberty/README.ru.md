# Приложения Liberty — инструкции по настройке

[English](README.md) · **Русский**

Все средства обхода блокировок, VPN и прокси, входящие в OpenWrt-Liberty, собраны в
одном разделе меню LuCI — **Liberty**. Здесь лежит отдельная инструкция для каждого
из них.

## Приложения не взаимозаменяемы

Они делятся на три разных типа, и «пустить весь трафик через него» в каждом случае
означает своё. Эта таблица сэкономит вам час.

| Приложение | Что это | Где настраивается | Может нести весь трафик? | Kill-switch |
|---|---|---|---|---|
| [**AmneziaWG**](amneziawg.ru.md) | WireGuard с маскировкой, устойчив к DPI | Network → Interfaces (в Liberty только состояние) | Да — маршрутизируемый туннель | [да](kill-switch.ru.md) |
| [**WireGuard**](wireguard.ru.md) | обычный WireGuard | Network → Interfaces (в Liberty только состояние) | Да — маршрутизируемый туннель | [да](kill-switch.ru.md) |
| [**OpenVPN**](openvpn.ru.md) | классический VPN-клиент | Liberty → OpenVPN | Да — маршрутизируемый туннель | [да](kill-switch.ru.md) |
| [**PassWall**](passwall.ru.md) | оболочка xray-core (VLESS, Reality, XHTTP…) | Liberty → PassWall | Да — но перехватом трафика, а не маршрутизацией | [да, в своём виде](passwall.ru.md#шаг-4--kill-switch) |
| [**Tailscale**](tailscale.ru.md) | mesh-VPN без настройки | Liberty → Tailscale | Только через **выходной узел** | [да](tailscale.ru.md#шаг-4--kill-switch) |
| [**Zapret**](zapret.ru.md) | обход DPI вообще без сервера | Liberty → Zapret | **Нет** — это не туннель | неприменим |

Первые три — обычные сетевые интерфейсы: ядро направляет в них пакеты, а firewall
решает, кому можно ими пользоваться. PassWall устроен иначе — он перехватывает
соединения правилами nftables и передаёт их xray-core, а не становится маршрутом, —
но **kill-switch к нему применим**, причём в том же виде: убрать forwarding
`lan ⇒ wan`, только без подстановки туннельной зоны вместо него. См.
[инструкцию по PassWall](passwall.ru.md#шаг-4--kill-switch).
Tailscale строит сеть между вашими собственными машинами; интернет-трафик пойдёт
через неё только если одна из машин назначена выходным узлом — и kill-switch он
принимает ровно так же, как OpenVPN. Zapret никуда трафик не уводит — он изменяет
пакеты так, чтобы оборудование DPI не смогло их распознать, и поэтому он
единственное здесь приложение, которому kill-switch настраивать не из чего.

## Перед началом

Веб-интерфейс донгла — **http://192.168.1.1** через USB-гаджет, адрес один и тот же
и с USB-хоста, и по Wi-Fi. Управление не зависит от модема, поэтому эксперимент,
оборвавший интернет, не отрежет вас от устройства.

Туннелю нужен работающий канал наружу. Если в модеме нет симкарты или нет передачи
данных, любой VPN-клиент будет бесконечно повторять попытки: `Network unreachable` в
журнале означает, что дело в модеме, а не в VPN.
